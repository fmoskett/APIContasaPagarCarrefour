Readme

Para essa solução do projeto foi utilizado o banco de dados SQL Compact  de  forma code first  que deve ser configurada no appsettings.json  (por padrão deixei em C:\fontes\contasapagar.db)e teste usando Selenium driver. 

Arquitetura consiste em uma webAPI rest separada em camadas e tratamento de exceções e LOG com log4net.  Também foi utilizado a versão 6.4.4
